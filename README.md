# Origami Tsuru
This is a simple HTML, CSS and JavaScript page to teach you how to build your own origami crane step by step.</br>
Just follow the 15 steps to make this origami.

## Steps
Each steps contains a short description and a reference image to ilustrate what it needs to be done

## Info
Bellow the steps, you'll find some information about the stories and legends related to the crane, specially in Japanese culture.
